# Engineering Portfolio

Mechanical and aerospace engineering portfolio of **Annalise Dantes**, a mechanical engineering student at the University of Florida (class of 2029).

**Live site: https://anna-rizelle.github.io/engineering-portfolio/**

## About this project

I'm interested in aerodynamics and CFD, mechanical design, propulsion and structures, and autonomous systems. This site documents the engineering projects I take on to build those skills, with an emphasis on showing the reasoning behind the work and not only the final result.

Each project page is organized around:

- the problem and its constraints
- the theory and equations involved
- the design and simulation methodology
- the tools used
- results, labeled as analytical, simulation, or experimental
- verification and validation: how the work was checked

Every project is labeled **Planned**, **In Progress**, or **Completed**, so it is always clear what has actually been done.

## What's on the site

- **Projects**: searchable and filterable project library with detailed technical pages
- **Skills**: each skill is tied to evidence, such as a linked project, instead of a proficiency percentage
- **About**, **Resume**, and **Contact**

## Built with

React, TypeScript, Vite, Tailwind CSS, React Router, Lucide icons, and KaTeX for equations. It is a static site with no backend or database, deployed to GitHub Pages with GitHub Actions.
